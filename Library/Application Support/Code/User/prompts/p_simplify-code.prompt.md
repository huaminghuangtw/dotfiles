Apply Steve Jobs' design thinking to simplify, clarify, and elevate whatever I give you — a product, a workflow, a piece of writing, a resume, or any creative challenge.

Work through these phases in order. Each phase contains a set of questions to apply to the input. Phase 4 (synthesis) is the final output.

## Phase 1: Strip to Essentials

Ask these questions and apply the answers to the input:

1. **How can I make this simpler?** — Strip away everything unnecessary. Find the core that actually matters.
  
  > Cut the redundant. Keep the essential.

2. **What's the one thing this absolutely must do perfectly?** — Identify the single most important function. Cut everything else.
3. **Where am I adding complexity that the recipient doesn't value?** — Spot over-engineering, feature bloat, and effort wasted on what nobody asked for.
4. **What am I including because I can, not because I should?** — Discipline over capability. Say no to good ideas to make room for great ones.

## Phase 2: Reframe from Zero

Now challenge the assumptions:

5. **What would this look like if I started from zero?** — No history, no legacy decisions. What would you build today?
6. **How would I design this for someone who's never seen anything like it?** — Beginner's mind. Eliminate insider assumptions and jargon.
7. **What would this look like if I designed it for myself?** — Forget market research and stakeholder opinions. What would genuinely satisfy you?

## Phase 3: Pursue Elegance

Now push toward beauty and flow:

8. **What would the most elegant solution be?** — Find the beautiful path. Elegance is not decoration; it's the fewest moving parts that solve the problem completely.
9. **What would this be like if it just worked magically?** — Design the invisible interface. The user shouldn't have to think about it.
10. **How can I make the complex appear simple?** — Find the accessible entry point. Make the hard look effortless.
11. **How can I make this feel inevitable instead of complicated?** — Natural flow. Each step should lead to the next without friction.

## Phase 4: Raise the Bar & Synthesize

Bring it all together:

12. **How would I make this insanely great instead of just good?** — Raise the standard. What's currently "acceptable" that should be remarkable?
13. **Where am I compromising that I shouldn't be?** — Identify the quality blind spots you've learned to live with.

Then produce the final simplified version incorporating all insights from phases 1–4.

## Power technique: Stack the questions

If the input is small or you need a quick audit, stack multiple questions into one pass:

> "How can I simplify? What's the core function? What would elegant look like?"

This creates a complete design-thinking audit in a single response.

## Constraints

- **Be ruthless with subtraction.** When in doubt, cut it out.
- **Keep it humanly achievable.** Push for greatness but don't suggest changes that require infinite resources.
- **Aesthetics and function are inseparable.** The simplified version should also feel better, not just be shorter.
- **Confused recipients don't engage.** If the result still requires explanation, it's not simple enough.
